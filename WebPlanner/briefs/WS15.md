## Acceptance tests (write first)

- Value snapshot unchanged after every task.
- Token lint: no literal outside the token files.
- Contrast: text ≥ 4.5:1, large text and UI parts ≥ 3:1 for every token pair used.
- Colour-vision simulation: safe, caution, limit and select distinguishable; second cue present.
- The same object selected from map, list and search shows the same card; Escape clears; history back/forward works.
- Every card number is manifest- or field-backed.
- Old URLs redirect into the right mode.
- Scrubber time equals the HUD clock.
- With the API unreachable, every static view works and the offline banner shows.

## Don't

Introduce React, a CSS framework or a chart library; leave a view half-migrated past V2; put colour on data that has no meaning; remove a number from a view.

## Fallback

If the shell is not complete at V2: revert the migrations, keep tokens, components and the selection sidebar inside the current layout.
