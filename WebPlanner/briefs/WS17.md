# 🧑‍🚀 WS17 brief — 3D scene (crew and chase camera)

> ✂️ **Backend demo cut (D69, Sat 21:16).** Task 5 (terrain for any plan) is dropped: there is no backend world tile service. The 3D scene uses the shipped chunks of the official route, labelled.

> 📌 **Goal.** Turn the existing first-person view (F20) into a place to watch the EVA: chase and overhead cameras, the crew pair, shadows from the Mars sun, the thread home in the scene, and terrain for any plan. **Feature:** U8 (Tier B). **Reviewers:** R (code), team lead (graphics).

## Owns

New files in `web/src/fp3d/`: `chase.ts`, `crew.ts`, `shadows.ts`, `thread3d.ts`, `worldtiles.ts`. Existing WS8 files change only with R's approval.

## Reads

The existing scene, `fp3d/*`, the mission state (WS15), the thread path function (WS16), `sun.json`, `tokens.json`, `config/design.yaml` (`3d:` block), the backend world tiles (F30) when available.

## Tasks in order

1. **Cameras:** chase (behind and above the crew, smoothed) and overhead, switchable with first-person; same clock as the HUD.
2. **Crew pair:** two simple stylised suited figures built from basic shapes in code; procedural walk cycle with speed from the timeline; no markings of any agency.
3. **Ground rings and thread:** a ring under each figure in the margin colour; the thread home as a line on the terrain.
4. **Shadows:** shadow map from the Mars-clock sun; automatic switch-off below 30 fps.
5. **Terrain for any plan:** load near tiles along any plan's route from the world tile service when the server is up; otherwise the shipped chunks of the official route.
6. **Restyle:** HUD and labels with tokens; Visual chips on figures, sky and haze; the "Simulated EVA · real terrain and data" label.

## Acceptance tests (write first)

- Existing F20 checks still pass: eye height 1.7 ± 0.1 m; skyline within 0.5° at the pad and all stations.
- ≥ 30 fps on the integrated-GPU laptop with shadows on (else shadows switch off).
- Crew position equals the mission-state position every frame; ring colour equals the margin state.
- Automatic 2D fallback unchanged.

## Don't

Import external character models without a recorded open licence; add agency insignia; change the first-person camera's validated geometry.

## Fallback

No figures: chase camera and thread only. No world tiles: official route only, labelled.
